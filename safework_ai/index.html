Ollama Local Setup Guide

1. Install Ollama Download from ollama.com.
2. Download Model Run in terminal: ollama run llama3
3. Enable Browser Access (REQUIRED)
Windows: Close Ollama from Taskbar, then run:
$env:OLLAMA_ORIGINS="*"; ollama serve
Mac/Linux: Close Ollama, then run:
OLLAMA_ORIGINS="*" ollama serve
Linux (Service): Run sudo systemctl edit ollama.service and add:
Environment="OLLAMA_ORIGINS=*" then restart.

Keys are saved locally in your browser.
