Ollama Setup: Step-by-Step Guide

⚠️ Resource Requirements:
  • Download: ~2.5 GB data required.
  • Disk Space: >4 GB for install + >4 GB for models.
  • Expectation: Setup takes time, but enables uninterrupted, private, and offline use once done.
Recommended Config: 8GB+ RAM, 4-core CPU (dedicated GPU preferred).
1. Install

Download OllamaSetup.exe and run it.

2. Download Model

Run in CMD or PowerShell:

ollama run llama3
3. Enable Browser (CMD)

Close Ollama (Tray), then run in CMD:

set OLLAMA_ORIGINS=* && ollama serve
1. Install

Download Ollama.zip and move to Applications.

Run sudo systemctl edit ollama.service and add:

Environment="OLLAMA_ORIGINS=*"

⚠️ Getting "Bind Error"?

Close Ollama from your System Tray (clock area) before running CMD commands.
