LLM Model Setup

Groq Cloud Setup:

  1. Go to Groq API Keys
  2. Create a free API key and paste it above.
  3. Recommended for speed and zero cost.

Google Gemini Setup:

  1. Visit Google AI Studio
  2. Generate a free API key for Gemini 2.5 Flash.
  3. Paste the key in the field above.

Ollama (Local) Setup:

  1. Download Ollama from ollama.com
  2. Run ollama run llama3 in your terminal.
  3. Crucial: To fix CORS, restart Ollama after running:
    $env:OLLAMA_ORIGINS="*" (Windows)
