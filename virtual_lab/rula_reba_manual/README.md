# ErgoCalc - Premium RULA & REBA Assessment Tool

**ErgoCalc** is a professional-grade web application designed for ergonomic assessments. It provides a digital interface for performing **Rapid Upper Limb Assessment (RULA)** and **Rapid Entire Body Assessment (REBA)** with exact scoring logic and a premium user experience.



## 🚀 Features

-   **Dual Assessment Modes**: Dedicated tools for both RULA (Upper Limb) and REBA (Entire Body).
-   **Exact Scoring Logic**: Implements the official scoring tables (Table A, B, and C) for accurate results.
-   **Premium UI/UX**: Dark mode design with neon glow effects, glassmorphism, and smooth transitions.
-   **Fully Responsive**: Works perfectly on Desktops, Tablets, and Mobile devices.
-   **Report Generation**: Built-in "Download Report" functionality (via Print to PDF).
-   **Reference Integration**: Direct access to official RULA/REBA worksheets and resources.

## 📂 Project Structure

## 🛠️ How to Use

1.  **Clone or Download** this repository.
2.  Open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).
3.  **Select Tool**: Choose RULA or REBA from the landing page.
4.  **Input Data**: Fill in the assessment details and select options for each step.
5.  **Calculate**: Click the "Calculate" button to see the score and action level.
6.  **Download**: Use the "Download Report" button to save the results.

## 🌐 Deployment (GitHub Pages)

This project is a static web application, making it perfect for **GitHub Pages**.

1.  Upload these files to a GitHub repository.
2.  Go to **Settings** > **Pages**.
3.  Under **Source**, select `main` (or `master`) branch and `/root` folder.
4.  Click **Save**.
5.  Your app will be live at `https://<your-username>.github.io/<repo-name>/`.
